# Calque

Калькулятор в виде текста: каждая строка считается сразу, результат виден справа. Это форк [grimalschi/calque](https://github.com/grimalschi/calque) на свежем [math.js](https://mathjs.org).

## Выражения

```
2 + 2 * 2
sqrt(3^2 + 4^2)
2 inch to cm
cos(45 deg)
```

## Переменные

Имена можно писать по-русски.

```
Цена = 120
Количество = 3
Цена * Количество
```

## Группы

Строка с двоеточием на конце становится группой. Всё, что ниже с отступом, складывается в её итог. Рядом с каждым значением видна его доля в группе.

```
Вкусности:
  Орехи:
    Грецкие = 100
    Арахис = 300
  Конфеты:
    Шоколадные = 100
    Мармеладные = 100
```

К значениям внутри групп можно обращаться через точку, регистр не важен:

```
Вкусности.Орехи.Арахис * 2
вкусности.конфеты / вкусности
```

## Таблицы

Если у соседних подгрупп повторяются имена полей, группа становится таблицей: подгруппы — её строки, а итог считается по каждому полю отдельно. Проценты тоже считаются внутри поля.

```
Салат:                 вес 150 · калории 135
  огурцы:
    вес = 100          · 67%
    калории = 35       · 26%
  сметана:
    вес = 50           · 33%
    калории = 100      · 74%
```

Итоги доступны через точку: `Салат.вес`, `Салат.калории`. Таблицы можно вкладывать друг в друга: `Обед` из `Салата` и `Супа` сложит их поля.

### Формулы

Строка `_имя = выражение` внутри группы — формула. Она считается, когда группа уже прочитана, поэтому её можно писать в любом месте группы, хоть до значений.

- Формула на уровне таблицы считается для каждой её строки. Результат виден справа от строки, а итог — в заголовке таблицы.
- Формула внутри строки считается только для неё.
- Итог формулы по таблице считается по итогам полей, если все поля формулы есть в итогах. Так `ккал / вес` даёт среднюю калорийность, а не сумму калорийностей. Если в формуле есть поле, которого в итогах нет, например записанное через `:=`, итог складывается по строкам.
- `(%)` в конце формулы дописывает к значению знак %.

```
Салат:
  _ккал = вес * калории
  _рацион = ккал / 1200 * 100 (%)
  огурцы:
    _клетчатка = вес * 0.02
    вес = 100
    калории := 35 / 100
  сметана:
    вес = 50
    калории := 100 / 100
```

В заголовке `Салат:` появится `вес 150 · клетчатка 2 · ккал 85 · рацион 7,1%`, справа от `огурцы:` — `ккал 35 (41%) · рацион 2,9% (41%)`. Значения доступны через точку: `Салат.ккал`, `Салат.огурцы.клетчатка`.

### Значения, которые не складываются

`имя := значение` работает как обычное присваивание, но в итоги групп не попадает. Это нужно для параметров вроде калорийности на 100 граммов или цены за штуку: складывать их бессмысленно, а в формулах они нужны.

## Единицы

Работают все единицы math.js (`5 kg to g`, `2 inch to cm`) и русские обозначения: `г`, `кг`, `мг`, `т`, `мл`, `л`, `мм`, `см`, `м`, `км`, `с`, `мин`, `ч`, `сут`, `кал`, `ккал`. Граммы с килокалориями сложить нельзя: вместо бессмысленной суммы будет ошибка.

```
1 кг to г
(2 ч + 30 мин) to мин
90 км / (1.5 ч)
```

Переменная с тем же именем важнее единицы: если написать `г = 9.81`, дальше `г` будет числом.

## Подсказки

Начните набирать имя, и внизу появятся подходящие переменные, группы и функции. После точки появляется содержимое группы. Tab подставляет первую подсказку, на телефоне подсказку можно нажать.

## Функции калькулятора

| Что | Пример |
|---|---|
| Интеграл на отрезке | `integral(x^2, x, 0, 3)` |
| Производная в точке | `ddx(x^3, x, 2)` |
| Сумма и произведение ряда | `Σ(k^2, k, 1, 10)`, `Π(k, k, 1, 5)` |
| Корень уравнения | `solve(x^2 == 2, x, 1)` — третье число задаёт начальное значение |
| Корни многочлена | `roots(1, -6, 11, -6)` — коэффициенты от старшей степени |
| Нормальное распределение | `normpdf(x, μ, σ)`, `normcd(от, до, μ, σ)`, `invnorm(p, μ, σ)` |
| Биномиальное и Пуассона | `binompdf(x, n, p)`, `binomcd(x, n, p)`, `poissonpdf(x, λ)`, `poissoncd(x, λ)` |
| Полярные координаты, градусы | `pol(1, 1)`, `rec(2, 30)` |
| Дроби | `fraction(1/3) + fraction(1/6)` |
| Матрицы | `det([[1, 2], [3, 4]])`, `inv(...)`, `lusolve(A, b)` |
| Статистика | `mean`, `median`, `std`, `variance` |
| Комбинаторика | `factorial(5)`, `combinations(5, 2)`, `permutations(5, 2)` |
| Системы счисления | `hex(255)`, `bin(10)`, `oct(8)` |

Всё остальное из [документации math.js](https://mathjs.org/docs/reference/functions.html) тоже работает.

## Комментарии

Всё после `#` — комментарий, в том числе в конце строки: `вес = 100 г # граммы`, `Салат: # обед`. Группы, формулы и `:=` с комментарием работают как без него.

## Предыдущий результат

```
2 * 2
last + 1
```

## Как поделиться

- **⧉** копирует выделенные строки вместе с результатами, а если ничего не выделено — весь расчёт. Так он читается в мессенджере. Общий отступ у выделенных строк убирается.
- **🔗** копирует ссылку. Весь текст лежит в самой ссылке, получатель откроет живой расчёт.

## Вкладки

Можно держать несколько расчётов: **+** сверху создаёт новый, **×** на текущей вкладке закрывает его. Название вкладки берётся из первой строки. Расчёты хранятся в браузере, в `localStorage` под ключом `calque_docs`.

Расчёт из чужой ссылки открывается в новой вкладке и ваши не трогает. Если такой расчёт уже есть, откроется он.

### Файлы

Меню **⋯** справа от вкладок:

- **Сохранить все вкладки** — скачивает `calque-ГГГГ-ММ-ДД.json.gz`: все расчёты в JSON, сжатом gzip. Подходит как резервная копия: Safari может стереть данные сайта, если его не открывать неделю.
- **Открыть файл…** — принимает `.json.gz`, `.json` и `.txt`, можно несколько сразу. Каждый расчёт открывается новой вкладкой, а те, что уже есть, повторно не добавляются.

Внутри архива — JSON вида `{"app": "calque", "version": 1, "docs": [{"title": "...", "text": "..."}]}`.

## Клавиши

| Действие | Клавиатура | Кнопки внизу |
|---|---|---|
| Повторить строку или выделение | Ctrl+D | — |
| Изменить число | выделить число, стрелки вверх и вниз | −1, +1: курсор на число |
| Изменить число шагом ×10 | Shift + стрелки | −10, +10 |
| Принять подсказку | Tab | нажать подсказку |
| Отступ | Tab, Shift+Tab | ⇥, ⇤ |
| Скрыть подсказки | Esc | — |

Шаг зависит от числа: у `2.5` шаг 0,1, у `120` — 1.

## Компонент

Calque можно встроить в свою страницу:

```html
<script src="math.min.js"></script>
<script src="calque-math.js"></script>
<script src="calque.js"></script>

<div class="interface">
    <div class="output" id="output"></div>
    <textarea class="input" id="input"></textarea>
</div>
<div id="toolbar"></div>

<script>
    new Calque(input, output, { toolbar: toolbar, storageKey: 'my-page' });
</script>
```

`storageKey: null` отключает сохранение в браузере, `onChange(text)` вызывается при каждом изменении текста, `setText(text)` подменяет весь текст. Вкладки подключаются отдельно, файлом `tabs.js`: пример — в `index.html`. Методы: `toText(lines)` — текст с результатами для строк, по умолчанию для всех; `selectedLines()` — строки, которые задевает выделение, `shareLink()` — ссылка на расчёт.
